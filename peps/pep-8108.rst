Abstract
========

This document describes the schedule and other details of the
2026 election for the Python steering council, as specified in
:pep:`13`. This is the steering council election for the 2027 term
(i.e. Python 3.16).


Election Administration
=======================

The steering council appointed the
`Python Software Foundation <https://www.python.org/psf-landing/>`__
Executive Director, Deb Nicholson, to administer the election.


Schedule
========

There will be a two-week nomination period, followed by a two-week
vote.

The nomination period will be: November 16, 2026 through `November 30, 2026 AoE
<https://www.timeanddate.com/worldclock/fixedtime.html?msg=Python+Steering+Council+nominations+close&iso=20261201T00&p1=3399>`_ [#note-aoe]_.

The voting period will be: December 2, 2026 through `December 16, 2026 AoE
<https://www.timeanddate.com/worldclock/fixedtime.html?msg=Python+Steering+Council+voting+closes&iso=20261217T00&p1=3399>`_ [#note-aoe]_.

Voter Roll
==========

All active Python core team members are eligible to vote. Active status
is determined as :pep:`described in PEP 13 <13#membership>`
and implemented via the software at `python/voters <https://github.com/python/voters>`_
[#note-voters]_.

Ballots will be distributed based on the `Python Voter Roll
<https://github.com/python/voters/blob/master/voter-files/>`_ [#note-voters]_
for this election.

While this file is not public as it contains private email addresses, the
`Complete Voter Roll`_ by name will be made available when the roll is
created.

Election Implementation
=======================

The election will be conducted using the `BetterVoting
<https://bettervoting.com>`__ service.

This election will use
`Multi-winner Bloc STAR <https://www.starvoting.org/multi_winner>`__
voting as `approved by the core team <https://discuss.python.org/t/64971>`__
and `codified <https://github.com/python/peps/pull/3958/files>`__ into :pep:`13`.

-------------

Create a `new election <https://bettervoting.com/new_election>`__.

Poll or Election?: ``Election``

How many races?: ``1``

Elected Office Title?: ``2027 Python Steering Council Election``

Election Description: ``Election for the Python steering council, as specified in PEP 13. This is the steering council election for the 2027 term.``

Voting Method: ``Basic Multi-Winner``

Number of Winners: ``5``

Which Voting Method?: ``STAR Voting``

After configuring Voting Method, the value should be ``STAR Voting with 5 Bloc winners``.

Select ``Next`` and opt not to publish the election yet, select ``Customize in Editor``.

In the navigation, select ``Preview Ballot`` and resolve any misconfigurations.

In the navigation, select ``Admin Home`` and the pencil edit button for the election.

Check ``Enable Start/End Times?``.

Time Zone: ``Midway Island, Samoa``

Start Date: ``12/02/2026, 01:00 AM``

End Date: ``12/17/2026, 01:00 AM``

Select ``Save`` to save the changes.

In the navigation, select ``Manage Voters``

Restricted to a Pre-Defined Voter List?: ``Yes``

How to Identity Voters?: ``BetterVoting-managed voter IDs``

Enter voter data using Email list from `Voter Roll`_ repository.

In the navigation, select ``Settings``

Contact Email: ``psf-election@python.org``

Randomize Candidate Order: ``Checked``

Allow Voters to Edit Vote: ``Checked``

Confirm That Voter Read Instructions: ``Checked``

Show Preliminary Results: ``Unchecked``

Make Election Publicly Searchable: ``Unchecked``

Note that 'Set Number of Rankings Allowed' has no effect on STAR voting methods,
only ranked voting methods.

* Voting is not open to the public, only those on the `Voter Roll`_ may
  participate. Ballots will be emailed when voting starts.
* Candidates are presented in random order, to help avoid bias.
